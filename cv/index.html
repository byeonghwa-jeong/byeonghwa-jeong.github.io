Current Research Projects

  • Interpretable population estimation from aerial imagery - Developing a two-stage semantic-segmentation and regression framework with ensemble self-training, pseudo-label filtering, temporal transfer, and landscape-class contribution maps; manuscript submission planned in 2026.
  • Population surface reconstruction using AlphaEarth embeddings - Developing a deep-learning framework that uses AlphaEarth satellite embeddings to reconstruct gridded population distributions while explicitly learning both populated and zero-population areas, with geographic-transfer evaluation across Taiwan, Ecuador, the Democratic Republic of the Congo, and Japan.
  • Scalable latent global routing for large-scale spatio-temporal graph learning - Developing ST-LAG, a latent-mediated graph architecture that combines sparse local graph propagation with node-to-latent global routing to model non-local dependencies without dense N x N node interactions.
  • Large-scale graph learning for population dynamics - Applying ST-LAG to continental-scale gridded population forecasting across the United States over more than 150,000 spatial units.
  • Scalable regional power-outage forecasting - Applying ST-LAG to hurricane-induced power-outage forecasting across the southeastern United States and developing an API for integration into ORNL’s EDGAR platform.
